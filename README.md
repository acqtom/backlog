# Task Backlog

Password-gated task backlog for Adriel and Alex, with High/Medium/Low priority, a star for top priority, a completed-tasks tracker, and a separate Yearly Goals panel.

## Usage

Open `index.html` in a browser. Password: `backlog123`.

Data is stored in the browser's `localStorage`/`sessionStorage`, so it's per-device/per-browser.

## Files

- `index.html` — markup
- `styles.css` — styling
- `app.js` — app logic
